# 📊 Sales Performance Dashboard

An interactive **Sales Performance Dashboard** built in **Microsoft Excel** to analyze business performance using the Global Superstore dataset. The dashboard provides dynamic insights into sales, profit, orders, customers, and regional performance through interactive visualizations and KPI reporting.

## 🎯 Project Objective

Develop an interactive sales dashboard to analyze business performance across regions, categories, products, and customer segments. The dashboard enables users to monitor KPIs, identify trends, and support data-driven decision-making.
