# 📊 Sales Performance Dashboard using Microsoft Excel

## 📌 Project Overview

This project is an end-to-end Sales Performance Dashboard built in Microsoft Excel using a real-world sales dataset. The objective was to transform raw sales data into meaningful business insights through data cleaning, KPI reporting, Pivot Tables, Pivot Charts, and an interactive dashboard.

---

## 🎯 Project Objectives

- Clean and prepare raw sales data for analysis.
- Analyze sales performance across regions, categories, and customers.
- Create interactive reports for business decision-making.
- Design a professional dashboard using Excel.

---

## 📂 Workbook Structure

- **Raw_Data** – Original dataset.
- **Clean_Data** – Cleaned and transformed dataset.
- **KPI_Summary** – Key business metrics.
- **Pivot_Tables** – Data summaries for dashboard visualizations.
- **Dashboard** – Interactive sales dashboard.
- **Documentation** – Project details and business insights.

---

## 📈 Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin (%)
- Total Quantity Sold
- Highest Sale
- Lowest Sale
- Number of Customers
